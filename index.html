Zoom to YouTube

本ツールは、MEGAMI合同会社が自社のZoomクラウド録画を、自社が運営するYouTubeチャンネルへアップロードするためだけに使用する社内ツールです。

プライバシーポリシー

  • 取得する情報：Zoomの録画ファイルと文字起こし、YouTubeへの動画アップロード権限（Google アカウントの認可情報）。
  • 利用目的：担当者が承認した録画を、指定の範囲でカットしてYouTubeにアップロードするためにのみ利用します。
  • 第三者提供：取得した情報を第三者に提供・販売することはありません。
  • 保存：録画ファイルは処理中のみ一時的に保存し、処理後に削除します。認可情報は暗号化して保管します。
  • Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。
  • 連携の解除：Google アカウントの「サードパーティのアクセス」からいつでも解除できます。
